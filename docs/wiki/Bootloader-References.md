# Bootloader References

ZFSBootMenu remains the default EFI boot path for Gentoo Stage4/Stage5 systems.
rEFInd is tracked as a relevant alternate or adjunct boot manager for workstation
and multi-boot validation.

Local rEFInd documentation mirror:

`/opt/repos/local/wget-synclocal/www.rodsbooks.com/refind`

Use the mirror for rEFInd boot stanzas, EFI loader discovery behavior,
workstation/multi-boot testing, UEFI fallback behavior, ESP layout decisions,
and boot manager comparison notes. Do not commit mirrored website content into
this repo.
